Rules the user set on 2026-11-18 for every Achilata piece (posts, stories, reels):
- No gradients.
- No quotation marks.
- No dashes or hyphens, in the visuals and in the captions.
- Never mix font weights or variants on the same line.
- It must not look or sound AI-made. Pieces should be very aesthetic and artistic, and work in the feed.
- Always follow the brand manual and the full context: Salta, the heat, the Tucumán product, two friends, a close and friendly tone.

Photo editing:
- Study each photo first: its light, shadow, real fuchsia color and texture.
- Keep a realistic background when it works; remove it only when needed, then use a palette color with shadows that match the original light.
- Adapt the format (4:5 or 9:16) by extending the photo's own background, and move the product within the frame if the composition needs it.
- Always work at maximum quality.

On generated images: only when truly necessary. The user offered a Hugging Face token for that case, but it must not be stored. Ask for it again when it is needed.

**Why:** The user wants the feed to look professional and handmade, not generic.

**How to apply:** Run `04_Contenido/reglas_de_contenido.md` before delivering any piece. Related: [[manual-marca-parametros-del-usuario]]
