Seguridad

Última actualización: {{sitio.actualizado}}.

La forma más segura de cuidar un dato es no guardarlo. Por eso esta web no tiene usuarios, contraseñas, base de datos ni pagos en línea.

Cómo está protegida la web

  • Conexión cifrada siempre. La web se sirve solo por HTTPS y le pide a tu navegador que nunca la abra sin cifrado.
  • Sin servidor que atacar. Es una web estática: no ejecuta código del lado del servidor ni guarda lo que escribís.
  • Sin código de terceros. Todas las fuentes, imágenes y scripts están alojados en la propia web. No cargamos publicidad, píxeles ni herramientas externas.
  • Política de seguridad de contenido estricta. El navegador solo ejecuta los scripts de esta web y bloquea cualquier otro, incluido el código insertado en la página.
  • Protección contra ventanas falsas. La web no se puede mostrar dentro de otra página, para evitar engaños por superposición.
  • Permisos apagados. La web no pide ni puede usar tu cámara, tu micrófono, tu ubicación ni otros sensores.
  • Formularios que no salen de tu dispositivo. El pedido y el presupuesto se calculan en tu navegador. Los datos solo viajan cuando vos mandás el mensaje por WhatsApp.
  • Dependencias revisadas. Las librerías de animación se revisan contra vulnerabilidades conocidas antes de cada publicación.

Cómo reportar un problema de seguridad

Si encontrás una falla de seguridad en esta web, te pedimos que nos avises por WhatsApp al {{whatsapp.0.texto}} antes de hacerla pública, con una descripción y los pasos para reproducirla. Te respondemos lo antes posible.
