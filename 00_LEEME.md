# Achilata Salta · Sistema del proyecto

Emprendimiento de venta de **achilata**, el helado típico tucumano, en **Salta Capital** durante la temporada de verano 2026-2027.
- Instagram: **@achilatasalta**.
- TikTok: a activar.

Esta carpeta es la memoria del proyecto. Las reglas para crear contenido están en `CLAUDE.md`, que se lee solo en cada sesión.

## Estructura

| Carpeta o archivo | Qué hay |
|---|---|
| `CLAUDE.md` | Reglas del proyecto y de cada pieza. Lo primero que se lee |
| `01_Contexto/` | El negocio, el producto, el mercado de Salta, el público y la competencia |
| `02_Marca/Manual de marca/` | **El manual de marca:** el `.ai` editable, con el manual y tus pautas originales; `Links/` con las imágenes vinculadas; `Exportes/` con el PDF y las páginas en PNG; `Respaldo/` con tu archivo original sin tocar |
| `02_Marca/identidad_y_tono.md` | Resumen de la marca y decisiones a confirmar |
| `03_Estrategia/` | Plan de lanzamiento y estrategia de redes |
| `04_Contenido/` | `reglas_de_contenido.md`, el checklist de cada pieza, y el registro de lo publicado |
| `05_Referencias/` | Producto, estilo de foto, marcas y cuentas de Instagram de referencia |
| `06_Assets/` | Logos en PNG, SVG y PDF en cada versión y color, y las tramas |
| `07_Pendientes.md` | Datos que faltan confirmar |

## Reglas del sistema
1. El manual de marca manda sobre cualquier otra cosa.
2. Lo marcado **[POR CONFIRMAR]** es una suposición y no se publica como dato.
3. Cada referencia nueva va a `05_Referencias/` con una línea de por qué sirve.
4. Lo publicado se registra en `04_Contenido/registro_publicaciones.md`.
